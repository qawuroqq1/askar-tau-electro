Сюда кладите собственные фотографии ASKAR TAU ELECTRO (цех, оборудование, выполненные объекты).
Затем откройте assets/js/images.js и укажите путь к файлу в нужной записи (src: "assets/images/own/имя.webp", demo: false).
Рекомендации: WebP или JPG, ширина 1600–2400 px для больших блоков и 1200 px для карточек, без водяных знаков.
