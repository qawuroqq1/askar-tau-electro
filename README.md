# Сайт ASKAR TAU ELECTRO

Статический сайт без сборки и зависимостей: откройте `index.html` в браузере или загрузите папку на любой хостинг (GitHub Pages, Netlify, Cloudflare Pages, обычный хостинг).

## Страницы

| Файл | Раздел |
|---|---|
| `index.html` | Главная |
| `about.html` | О компании |
| `products.html` | Продукция |
| `services.html` | Услуги |
| `production.html` | Производство (этапы) |
| `portfolio.html` | Портфолио (фильтр + просмотр фото) |
| `contacts.html` | Контакты и форма заявки |
| `404.html` | Страница «не найдено» |

Языки: русский, қазақша, English (переключатель в шапке, выбор запоминается).

## Куда вносить информацию: 3 файла

| Что изменить | Файл |
|---|---|
| Телефоны, WhatsApp, Telegram, e-mail, адрес, режим работы, карта, БИН, соцсети, слоган | `assets/js/config.js` |
| Любые тексты на трёх языках | `assets/js/i18n.js` |
| Фотографии | `assets/js/images.js` |

Пока значение в `config.js` равно `null`, на сайте показывается аккуратная заглушка «Будет добавлено». Впишите значение — и оно сразу появится везде: в шапке контактов, подвале и на странице «Контакты».

**Форма заявки** начнёт работать автоматически, когда будет указан `email` (откроется почтовое приложение) или `whatsapp` (откроется чат). Для отправки без почтового клиента позже можно подключить Formspree, Web3Forms или Telegram-бота.

## Как заменить фотографии на свои (дизайн и HTML не трогаем)

1. Положите файл в `assets/images/own/`.
2. В `assets/js/images.js` найдите нужный ключ (например `hero` — главный экран) и замените строку на:
   ```js
   hero: own("assets/images/own/ceh.webp", { ru: "Цех ASKAR TAU ELECTRO", kk: "...", en: "..." }, "50% 40%"),
   ```
   Третий параметр — точка кадрирования, чтобы на телефоне в кадр попадало главное.
3. Значок «Демо-фото» исчезнет автоматически.

### Демонстрационные изображения

- Временные фото взяты с Unsplash (бесплатная коммерческая лицензия Unsplash License, без водяных знаков). Сейчас они загружаются с CDN Unsplash сразу в WebP/AVIF и в нужном размере (`srcset`), с lazy loading.
- Все они помечены на сайте значком «Демо-фото», а в подвале есть пояснение и список источников. Они **не выдаются** за производство или проекты компании.
- Чтобы хранить их локально в проекте, выполните один раз: `bash tools/download-demo-images.sh` — фото скачаются в `assets/images/demo/`, сайт переключится на локальные файлы.

### Визуализации изделий

Присланные изображения (ворота, лестницы, шкафы, навесы, экраны, МАФ) разрезаны на отдельные кадры и сохранены в WebP: `assets/images/products/`. На сайте они подписаны как «Визуализация».

## Логотип

- `assets/brand/logo-original.jpg` — оригинал без изменений.
- `assets/brand/logo.webp` / `logo-transparent.png` — тот же логотип, у которого только убран белый фон (пропорции, цвета и элементы не менялись). Используется в шапке; в тёмном подвале логотип стоит на белой подложке, чтобы не менять фирменные цвета.
- `assets/brand/favicon.png` — знак «AT» для вкладки браузера.

**Рекомендация:** запросите у дизайнера логотип в векторе (SVG, PDF, AI или EPS) — исходный файл был растровым JPG на белом фоне. Из вектора получится идеально резкая версия для шапки и, при желании, официальная светлая версия для тёмного фона (белые буквы + жёлтая молния), которую должен утвердить владелец бренда.

## Цвета и шрифты

- Тёмно-синий из логотипа `#09274B`, жёлтый (молния) `#FEBE05`, графит `#12161C`.
- Шрифты: Exo 2 (заголовки — перекликаются с геометрией логотипа) и Inter (текст); оба поддерживают казахские буквы.
- Все цвета — переменные в начале `assets/css/style.css`.
